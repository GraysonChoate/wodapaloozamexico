## The outcome we are pursuing

The current work is a strong edit presented in a scrolling window. The next pass must
make selected images behave as *things in space*: frames that expand, plates that
collapse, type that occupies a depth plane, and source material that can be physically
felt. It must never become a generic effects reel.

The governing sentence is:

> **One dominant image, one supporting real material, one graphic action.**

When an effect does not improve narrative pressure, place, or the transition into the
next image, it does not belong.

## Reference grammar — use, do not imitate

The supplied screen recordings were reviewed as moving sequences, not as still
moodboards:

| Reference | Its single job here |
|---|---|
| Motion Frame | editorial interruption: crop, rotate/lock, abrupt controlled reframing |
| Sea Serenade | calm scale choreography: contained image to full bleed, full bleed back to object, black holds |
| AI Film Studio | designed image planes: spatial type, deliberate framing, quiet metadata |

Transferable moves:

- contained plate → full bleed;
- full bleed → contained plate/card;
- split/crop windows;
- restrained CSS 3D perspective, a short tilt/rotation, then a decisive lock;
- foreground / typography / background moving at different rates only where the source
  supports it;
- type behind a real silhouette;
- scale-through as a transition, not a default animation;
- black holds followed by a deliberate image re-entry;
- slow suspended moments followed by a sharper editorial release;
- small metadata that belongs to the composition rather than dashboard furniture;
- real paper, sticker, and card layers.

Do **not** import reference-site footage, permanent navigation rails, ecommerce UI,
dark studio styling, or effects just because a reference used them.

## Review and build protocol

For every enhancement:

1. **Inspect the actual source first.** If it cannot pay for the proposed move, change the
   move rather than fabricate the source.
2. Build one isolated prototype; do not alter unrelated beats.
3. Ship headed-browser desktop and mobile states plus forward, reverse, and fast-scroll
   recordings in `audit/<milestone>/`.
4. Codex reviews it against the motion grammar and source rules before reuse.
5. Only then extract a reusable rule or material treatment.

Approval requires: real depth before visible effect; clean source boundaries; legibility at
1440×900 and 375×812; smooth reversible motion; no-JS/reduced-motion fallbacks; and a
specific narrative reason.

Reject or revert halos, detached mattes, duplicate-image ghosting, generic decoration,
partially clipped watermarks, or transitions that read as scrolling artifacts rather than
cinematic editorial decisions.
